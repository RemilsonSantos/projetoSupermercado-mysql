# Projeto Supermercado — MySQL

## Sobre o projeto

Este projeto consiste no desenvolvimento de um banco de dados relacional para simular o gerenciamento de um supermercado.

O objetivo foi praticar conceitos fundamentais de SQL e modelagem de banco de dados.

## Tecnologias utilizadas

- MySQL
- MySQL Workbench
- SQL

## Funcionalidades e conceitos aplicados

- Criação de banco de dados e tabelas.
- Definição de chaves primárias (PRIMARY KEY).
- Relacionamento entre tabelas com chaves estrangeiras (FOREIGN KEY).
- Inserção de registros (INSERT INTO).
- Consultas de dados (SELECT).
- Relacionamento entre tabelas utilizando INNER JOIN.

## Estrutura do banco

- Produtos
- Clientes
- Funcionários
- Vendas

## Aprendizados

Durante o desenvolvimento, pratiquei a criação e organização de bancos de dados relacionais, integridade referencial e consultas SQL.
